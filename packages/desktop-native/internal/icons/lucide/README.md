# Lucide

These SVGs are the Lucide icons the web dashboard imports from `lucide-react`
1.59.0, written from its icon node data with Lucide's default attributes (24×24,
`currentColor` stroke 2, round caps and joins). Files are named after the web
import in kebab case (`Layers3` is `layers-3.svg`). `LICENSE` retains Lucide's
ISC license and the MIT notice for Feather-derived icons. The app embeds these
files; nothing is fetched or generated at build time.
