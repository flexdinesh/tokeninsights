# Geist

`geist-latin-variable.ttf` is `packages/web/public/fonts/geist-latin-variable.woff2`
(`@fontsource-variable/geist` 5.2.8, Latin upright variable weight) decompressed
to TrueType with fontTools 4.55.3 (`fonttools ttLib.woff2 decompress`), because
native text engines register TrueType/OpenType only. Browser and native use the
same glyphs and metrics.

The upstream font is https://github.com/vercel/geist-font. `OFL.txt` retains its
SIL Open Font License. The app embeds this file; no font is fetched at runtime.
