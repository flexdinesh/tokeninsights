# DM Sans

`dm-sans-latin-variable.woff2` is the Latin, upright variable-weight subset from
`@fontsource-variable/dm-sans` 5.2.8:
https://cdn.jsdelivr.net/npm/@fontsource-variable/dm-sans@5.2.8/files/dm-sans-latin-wght-normal.woff2

The upstream font is https://github.com/googlefonts/dm-fonts. `OFL.txt` retains
the SIL Open Font License from the Google Fonts DM Sans source. The browser loads
this committed asset from its serving origin; no font CDN is used at runtime.
