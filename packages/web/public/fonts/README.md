# Geist

`geist-latin-variable.woff2` is the Latin, upright variable-weight subset from
`@fontsource-variable/geist` 5.2.8:
https://cdn.jsdelivr.net/npm/@fontsource-variable/geist@5.2.8/files/geist-latin-wght-normal.woff2

The upstream font is https://github.com/vercel/geist-font. `OFL.txt` retains its
SIL Open Font License. The browser loads this local file; no font is fetched at runtime.
