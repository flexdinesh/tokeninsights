# TokenInsights

Track token usage across OpenCode, Pi, Codex, and Claude Code in the desktop app,
a browser or a terminal. One personal backend reads durable usage metadata and
keeps SQLite history on the machine where the harnesses run.

## Start here

1. [Install desktop and CLI](/install), or choose CLI-only.
2. [Open a dashboard](/getting-started) and explore saved usage.
3. [Understand collected metadata](/privacy).
4. [Connect to another machine](/remote) with explicit SSH or temporary TCP.

Compare usage by time, repository, model, provider, harness and session. Inspect
prompt-side session context load alongside token totals. Confirmed usage and
ambiguous excluded usage stay separate.

Launch captures usage while saved history stays readable. Explicit **Refresh**
captures again; filters and reload only query. There is no periodic scanning,
account setup or separately managed server.
