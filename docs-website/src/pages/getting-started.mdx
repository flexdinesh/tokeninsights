# Getting started

Install on the machine where you use OpenCode, Pi, Codex or Claude Code:

```sh
curl -fsSL https://raw.githubusercontent.com/flexdinesh/tokeninsights/main/install-desktop.sh | sh
tokeninsights
```

Ensure `~/.local/bin` is on PATH. Desktop includes CLI/backend. [Install](/install) also covers CLI-only and release channels.

## Open saved usage

```sh
tokeninsights tui
tokeninsights web
```

Viewers share one backend and open saved history while all four supported harnesses
are captured and processed. Published usage appears as processing finishes.
Closing one viewer leaves others active.

After another harness run, use **Refresh** in the dashboard to capture new usage,
or launch a viewer again. Reload and filters only query saved results. There is
no periodic source scanning.

To skip launch capture:

```sh
tokeninsights --capture=false
tokeninsights tui --capture=false
```

Pending accepted processing still resumes. If you have not used a supported harness,
there may be no usage yet. Continue with [local usage](/local-usage), or
[connect explicitly to another machine](/remote).
