# Install

Install on macOS or Linux, amd64 or arm64. Products are prebuilt GitHub Release downloads; no Go or Node installation is required.

## CLI, TUI and browser dashboard

Latest stable:

```sh
curl -fsSL https://raw.githubusercontent.com/flexdinesh/tokeninsights/main/install.sh | sh
```

Latest main build that passed checks:

```sh
curl -fsSL https://raw.githubusercontent.com/flexdinesh/tokeninsights/main/install-main.sh | sh
```

Ensure `~/.local/bin` is on PATH, then run `tokeninsights tui` or `tokeninsights web`.

## Desktop experiments

Native MyGo:

```sh
curl -fsSL https://raw.githubusercontent.com/flexdinesh/tokeninsights/main/install-mygo.sh | sh
```

Electron, using the same React dashboard as the browser:

```sh
curl -fsSL https://raw.githubusercontent.com/flexdinesh/tokeninsights/main/install-electron.sh | sh
```

Both apps include their backend and can run together with TUI/web. MyGo is the default for `tokeninsights web`; override with `--open=electron`, `--open=mygo` or `--open=browser`. Save the selection with `tokeninsights config set viewer.open MODE`. Hosted URLs open in the browser.

macOS apps appear in `~/Applications`; Linux apps have distinct desktop entries. No login service is installed. The shared backend starts when a viewer opens and stops after the last viewer disconnects. Linux MyGo needs GTK 3 and a supported graphics environment; it uses native Go UI, not WebKit.

## Hosted server

```sh
curl -fsSL https://raw.githubusercontent.com/flexdinesh/tokeninsights/main/install-server.sh | sh
```

Installing the server does not launch it. See [self-hosting](/self-hosting) for storage and authentication setup.

## Channels and updates

Every product script accepts `--channel=stable` or `--channel=main`:

```sh
curl -fsSL https://raw.githubusercontent.com/flexdinesh/tokeninsights/main/install-mygo.sh | sh -s -- --channel=main
```

Rerun the installer to update. Stable/main replace that product; the two desktop experiments coexist. Downloads and checksums come from GitHub Releases or the rolling main prerelease. Failed downloads preserve the existing installation. Close viewers before an incompatible backend upgrade; installation never terminates them or changes usage data.

Homebrew and Go source installs are no longer distribution channels. Developers build from a checkout using the repository's mise tasks.
