# Install

macOS/Linux, amd64/arm64. Products are prebuilt GitHub Release downloads.
No Go or Node installation is required.

## Desktop

The desktop installer includes the CLI and backend:

```sh
curl -fsSL https://raw.githubusercontent.com/flexdinesh/tokeninsights/main/install-desktop.sh | sh
tokeninsights
```

Desktop uses WKWebView on macOS and WebKitGTK 4.1 on Linux. It shows
the same dashboard as the browser and can coexist with TUI/web.

## CLI, TUI and browser

```sh
curl -fsSL https://raw.githubusercontent.com/flexdinesh/tokeninsights/main/install.sh | sh
tokeninsights tui
tokeninsights web
```

The CLI-only product includes the backend. Bare `tokeninsights` still opens
desktop, so install that app or explicitly use TUI/web.

An unavailable desktop fails with installation guidance, without opening a browser.

## Paths, channels and updates

Command links use `~/.local/bin`; add it to PATH if needed. The most recent CLI or
desktop install owns `tokeninsights`, and both warn when PATH runs another command.
macOS apps appear in
`~/Applications`; Linux apps have distinct desktop entries. Product files live
under `${XDG_DATA_HOME:-~/.local/share}/tokeninsights/products/`.
No login service is installed. The backend starts on demand and stops after its
last lease and reconnect grace.

Every product script accepts `--channel=stable` (default) or `--channel=main`.
Main has no macOS Intel build:

```sh
curl -fsSL https://raw.githubusercontent.com/flexdinesh/tokeninsights/main/install-desktop.sh | sh -s -- --channel=main
```

CLI's latest main build also has `install-main.sh`. Rerun to update.
Both installers recognize CLI links from installer-owned MyGo products before the
desktop rename; they update the command without deleting the old product or launcher.
Downloads/checksums come from stable releases or the rolling main prerelease.
Failed downloads preserve the existing installation. Close viewers before an
incompatible backend upgrade; installation never terminates them, migrates history
or deletes usage files. Homebrew and Go source installs are retired.
