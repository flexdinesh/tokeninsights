# Install

Install TokenInsights on each machine where you use OpenCode, Pi, Codex, or Claude
Code.

## Homebrew

```sh
brew install flexdinesh/tap/tokeninsights
```

## Go

```sh
go install github.com/flexdinesh/tokeninsights/packages/cli/cmd/tokeninsights@latest
```

`@latest` installs the latest stable version, published manually from `main`. Use
`@v0.1.3` to pin a stable version.

For the latest `main` commit that passed native CI:

```sh
go install github.com/flexdinesh/tokeninsights/packages/cli/cmd/tokeninsights@edge
```

Make sure the directory containing the installed binary is on your `PATH`.

`main` and feature branches omit generated dashboard assets, so direct
`go install ...@main` is unsupported. To build from a checkout, run `mise run setup`
and `mise run build:web` first. mise build, test, and lint tasks generate these
assets automatically.

See [release channels and workflow](https://github.com/flexdinesh/tokeninsights/blob/main/docs/release.md).

## Desktop app (optional)

The desktop app is a thin viewer for macOS and Linux (amd64, arm64). With it
installed, `tokeninsights web` and `tokeninsights browse` open the dashboard in an
app window instead of a browser tab. The CLI still collects, stores and serves
usage; install the CLI first.

```sh
curl -fsSL https://raw.githubusercontent.com/flexdinesh/tokeninsights/main/install.sh | sh
```

The script downloads the app from the latest release, verifies its checksum and
installs it for the current user:

- macOS: `~/Applications/TokenInsights.app`.
- Linux: `~/.local/share/tokeninsights-desktop/` plus a desktop entry that handles
  `tokeninsights://` links. The app needs WebKitGTK 4.1 (`libwebkit2gtk-4.1-0` on
  Debian/Ubuntu, `webkit2gtk4.1` on Fedora, `webkit2gtk-4.1` on Arch).

Rerun the script to upgrade. The app is not notarized; install it with the script
rather than downloading the archive in a browser, which macOS Gatekeeper blocks.
There is no Windows app.
