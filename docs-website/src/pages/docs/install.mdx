# Install

macOS/Linux, amd64/arm64. Stable products are prebuilt GitHub Release downloads.
No Go or Node installation is required.

## Desktop and CLI

The installer includes the desktop app, CLI and backend:

```sh
curl -fsSL https://raw.githubusercontent.com/flexdinesh/tokeninsights/main/install.sh | sh
tokeninsights
```

Desktop uses WKWebView on macOS and WebKitGTK 4.1 on Linux. It shows
the same dashboard as the browser and can coexist with TUI/web.

## Servers without a display

```sh
curl -fsSL https://raw.githubusercontent.com/flexdinesh/tokeninsights/main/install.sh | sh -s -- --cli-only
tokeninsights tui
tokeninsights web
```

The CLI-only product includes the backend. Bare `tokeninsights` still opens
desktop, so install that app or explicitly use TUI/web. Repeat `--cli-only` when
updating; a rerun without it installs desktop.

An unavailable desktop fails with installation guidance, without opening a browser.

## Paths, channels and updates

Command links use `~/.local/bin`. When that is not on PATH, the installer adds one
marked line to your shell profile: `.zshenv` for zsh, `.bashrc` and a login profile
for bash, `conf.d/tokeninsights.fish` for fish, otherwise `.profile`. Open a new
shell, or run the command it prints. `--no-modify-path` opts out. Non-interactive
SSH may skip these profiles; set `remote.command` if `connect` cannot find the
command. The most recent CLI or desktop install owns `tokeninsights`, and both warn
when PATH runs another command.
macOS apps appear in
`~/Applications`; Linux apps have distinct desktop entries. Product files live
under `${XDG_DATA_HOME:-~/.local/share}/tokeninsights/products/`.
No login service is installed. The backend starts on demand and stops after its
last lease and reconnect grace.

`install.sh` installs the latest stable release. Rerun to update.
Both products recognize CLI links from installer-owned MyGo products before the
desktop rename; they update the command without deleting the old product or launcher.
Downloads/checksums come from stable releases.
Failed downloads preserve the existing installation. Close viewers before an
incompatible backend upgrade; installation never terminates them, migrates history
or deletes usage files. Homebrew and Go source installs are retired.

## Unreleased builds

Install any branch, tag or full commit SHA (default `main`) by building it on your
machine. This needs `git` and [mise](https://mise.jdx.dev); mise installs the
locked Go, Node and pnpm. No CI publishes these builds.

```sh
curl -fsSL https://raw.githubusercontent.com/flexdinesh/tokeninsights/main/install-dev.sh | sh -s -- --ref=my-branch
curl -fsSL https://raw.githubusercontent.com/flexdinesh/tokeninsights/main/install-dev-native.sh | sh
```

`install-dev.sh` installs desktop, or the CLI with `--cli-only`, and replaces a
stable install of the same product. `install-dev-native.sh` installs the
experimental TokenInsights Native app beside desktop; it never takes over the
`tokeninsights` command or edits shell profiles. `tokeninsights --version` shows
`src.<sha12>`. The source checkout is cached in
`${XDG_CACHE_HOME:-~/.cache}/tokeninsights/source`; delete it to reclaim space.
