# Maintenance

TokenInsights keeps raw evidence and a published generation of processed usage.
SQLite uses pooled reads and a serialized WAL writer. PostgreSQL uses a dedicated
owned writer and pooled snapshot reads.

## Reprocess local data

```sh
tokeninsights data reprocess
tokeninsights data wait
```

Reprocessing is explicit, never automatic. It keeps the published generation until
the replacement is complete. Local data maintenance has a 30-second visibility wait.
If reprocessing exceeds that wait, `data wait` resumes the saved generation without
starting another rebuild. Persistent `processing_failed` errors can be recovered with
`data reprocess`. Raw evidence and the old published generation remain intact.

Keep a stopped backup of the paired databases and application guard before
maintenance.

## Backups

Application pairing persists `<canonical-token-path>.application.json`, containing
only the application instance ID. Keep this guard with both databases in stopped
backups. A missing or replaced app database fails closed to preserve credential
revocations. Restore the matched set; do not delete the guard to bypass recovery.

## Incompatible data

Only current schemas are supported; incompatible databases reject without mutation.
There are no imports or migrations. Storage uses collector schema **20**, token SQLite
schema **1**, PostgreSQL token/account schemas **1/2**, personal application SQLite
schema **2**, hosted application SQLite schema **3** and job SQLite schema **1**.

For `incompatible_application_database` in local `tui`, `web`, or `data` commands,
the error prints the resolved config and application database paths. The database
has an unsupported schema version or role. Close processes using it, delete that
application database and its `-wal`/`-shm` files if present, then rerun the command.
This resets local accounts and credentials, preserving the separate token database
and config. Pairing/backup errors instead require restoring the matched backup.

If you encounter incompatible data, delete the old local data:

```sh
rm -rf ~/.local/share/tokeninsights
```

Then reinstall TokenInsights using your preferred [installation method](/install).
Fresh collection rebuilds usage from retained sources.
